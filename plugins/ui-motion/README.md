# ui-motion

A small Claude Code plugin with two UI motion skills:

| Skill | Use it for |
|---|---|
| `kinetic-inflated-hero` | Full-viewport kinetic typography heroes with inflated physical letterforms, Matter.js-style motion, Pretext-inspired behavior, SVG goo/blur filters, and a signature invisible-word effect. |
| `scroll-blur-manifesto` | Quiet editorial manifesto sections where large text resolves from a blurred ghost layer into sharp copy on scroll with Lenis + GSAP ScrollTrigger. |

These skills were extracted from the Zine homepage direction: a loud electric-blue kinetic hero followed by a calm Lightfield-style blur-to-sharp manifesto.
